For global guidance and suggestions for using icons library with OUDS Web, please see the [icons page in foundation documentation]([[docsref:foundation/icons]]).

Icons’ size depends on where they are placed in the page content, so please make sure to either use our utilities provided in this page or follow the design. Icons size utility classes are designed to be used upon `<img />`, `<svg>` or even icon font, wherever the icon is.

Every icon size utility class presented in here has the common following code:

## Headings

Here are the rules to follow for headings. These icons’ sizes are responsive.

<details class="mb-medium">
  <summary>See the <strong>sizes</strong> associated to classes</summary>

  <div class="table-responsive">
    <table class="table">
      <thead>
        <tr>
          <th>Icon class</th>
          <th>Values from `2xs` to `sm`</th>
          <th>Values from `md` to `lg`</th>
          <th>Values for `xl` and upper</th>
        </tr>
      </thead>
      <tbody>
      {
        iconHeadingSize.map((level) => (
          <tr>
            <td>
              {level === 'heading-xlarge-size-large' && (<code>{'.hxl-large-icon'}</code>)}
              {level === 'heading-xlarge-size-medium' && (<code>{'.hxl-medium-icon'}</code>)}
              {level === 'heading-xlarge-size-small' && (<code>{'.hxl-small-icon'}</code>)}
              {level === 'heading-large-size-large' && (<code>{'.hl-large-icon'}</code>)}
              {level === 'heading-large-size-medium' && (<code>{'.hl-medium-icon'}</code>)}
              {level === 'heading-large-size-small' && (<code>{'.hl-small-icon'}</code>)}
              {level === 'heading-medium-size-large' && (<code>{'.hm-large-icon'}</code>)}
              {level === 'heading-medium-size-medium' && (<code>{'.hm-medium-icon'}</code>)}
              {level === 'heading-medium-size-small' && (<code>{'.hm-small-icon'}</code>)}
              {level === 'heading-small-size-large' && (<code>{'.hs-large-icon'}</code>)}
              {level === 'heading-small-size-medium' && (<code>{'.hs-medium-icon'}</code>)}
              {level === 'heading-small-size-small' && (<code>{'.hs-small-icon'}</code>)}
              {level === 'body-large-size-large' && (<code>{'.bl-large-icon'}</code>)}
              {level === 'body-large-size-medium' && (<code>{'.bl-medium-icon'}</code>)}
              {level === 'body-large-size-small' && (<code>{'.bl-small-icon'}</code>)}
              {level === 'body-medium-size-large' && (<code>{'.bm-large-icon'}</code>)}
              {level === 'body-medium-size-medium' && (<code>{'.bm-medium-icon'}</code>)}
              {level === 'body-medium-size-small' && (<code>{'.bm-small-icon'}</code>)}
            </td>
            {
              screenSize.map((size) => (
                <td>
                  <code>{getTokenValue(`$ouds-size-icon-with-${level}-${size}`).slice(0, -2) / 16}rem</code> ({getTokenValue(`$ouds-size-icon-with-${level}-${size}`)})
                </td>
              ))
            }
        </tr>
        ))
      }
      </tbody>
    </table>
  </div>
</details>

You should not use any icon with our `.display-*` font sizes, because we prefer to keep the place for the text.

## Decorative

Here are the rules to follow for decorative icons. Be careful using these icons’ sizes because they are not responsive. Check out for [more information about accessibility in our documentation]([[docsref:/foundation/icons#icon-accessibility]]).

    <table class="table">
      <thead>

          <th>Values</th>
        </tr>
      </thead>
      <tbody>
      {
        iconDecorativeSize.map((level) => (
          <tr>
            <td>
              <code>.{level}-icon</code>
            </td>
            {
              <td>
                <code>{getTokenValue(`$ouds-size-icon-${level}`)}</code>
              </td>
            }
        </tr>
        ))
      }
      </tbody>
    </table>
  </div>
</details>
