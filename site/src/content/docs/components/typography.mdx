### Accessibility


To ensure accessibility, make sure you choose the HTML tags you use, based on their **semantic meaning**; whether it is a heading, plain text, or a snippet of code, you should not use the same tag, regardless of how it appears on screen. Each tag conveys its own semantic meaning, which is communicated to screen readers.

## [[comp]] Heading

Heading is a UI element that styles typography to structure content and define the hierarchy of information within an interface. The heading features multiple sizes options, to help users quickly understand the organization of a page or section. Variants automatically adjust across breakpoints to ensure optimal readability on all devices. Heading serve as the primary entry point for visual navigation.

All HTML headings, `<h1>` through `<h6>`, are available. Each class sets `font-size`, and also `line-height`, `letter-spacing`, `font-weight: bold`, and `max-width`. If you want to get rid of the `max-width`, use our `.mw-none` [width utility]([[docsref:/utilities/sizing]]). Here are the associated `font-size`s depending on the breakpoints.

The display features large type sizes that capture attention and create strong visual emphasis. We provide `.display-*` from `large` through `small`. Each class sets `font-size`, and also `line-height`, `letter-spacing`, `font-weight: bold`, and `max-width`. If you want to get rid of the `max-width`, please make sure to use our `.mw-none` [width utility]([[docsref:/utilities/sizing]]). Here are the associated `font-size`s depending on the breakpoints.

## [[comp]] Body

Body is a UI element that styles typography for common text content like paragraphs, descriptions, and informational messages. The body features multiple size options, to allow content importance to be expressed while maintaining consistency. Variants automatically adjust across breakpoints to ensure optimal readability on all devices. Body prioritize readability and provide a comfortable reading experience.

Regular body text forms the core of your content. Body text has three size levels: large (for emphasis), medium (default), and small (for supporting information). Each class sets `font-size`, `line-height`, `letter-spacing`, and `max-width`. To remove the `max-width`, use the `.mw-none` [width utility]([[docsref:/utilities/sizing]]). Body texts use `font-weight: normal` by default, but can use other font weights as needed through our [font weight utilities]([[docsref:/utilities/text#font-weight]]).

## [[comp]] Label

Label is a UI element that styles typography for compact interface components such as buttons, form fields, badges, and other small elements. The label is non-responsive and maintains a fixed size across all breakpoints. This ensures visual consistency and predictable behavior within space-constrained UI elements. Labels are preferred when content is displayed within small components.

Labels have four size levels: xlarge, large, medium, and small. Each class sets `font-size`, `line-height`, `letter-spacing`, and `max-width`. To remove the `max-width`, use the `.mw-none` [width utility]([[docsref:/utilities/sizing]]). Label texts use `font-weight: normal` by default, but can use other font weights as needed through our [font weight utilities]([[docsref:/utilities/text#font-weight]]).

## [[comp]] Code

Code element is a UI element that styles typography for technical content like code snippets, commands, system values, and identifiers. The code employs a monospace typeface to maintain character alignment and enhance the readability of structured content. Offered in one size, it ensures a uniform presentation of technical information across the product. Its application should be restricted to content that necessitates a precise code-like representation.

### Inline code

Use the `<code>` element to mark short code snippets within text. The `<code>` element uses the monospace code font stack and is styled to stand out from surrounding text.

<Example buttonLabel="inline code" code={`For example, <code>&lt;section&gt;</code> should be wrapped as inline.`} />

### Code blocks

Use `<pre><code>` for displaying multiple lines of code. The `<pre>` element preserves whitespace and formatting, particularly indentation, while the `<code>` element marks the content as code.

<Example buttonLabel="multiline code" code={`<pre><code>

</code></pre>`} />
