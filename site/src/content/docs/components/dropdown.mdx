<Callout type="negative" title="Draft component">
  The dropdown menu component is not yet designed, and this component is only a draft for the moment. It will be updated in the future with the final design and will certainly need adjustments regarding the DOM. Use it as a temporary component to speed up your development.

  Please refer to the [Dropdowns in the Boosted documentation](https://boosted.orange.com/docs/components/dropdowns/) to have a full view of the dropdown menu component and its variations. The DOM should be the same as the Boosted one.
</Callout>

## Dropdown

Be sure to adapt the semantic of the tags you use for the dropdown items. For example, use `<button>` for actions in the page and `<a>` for navigation links.

<Example buttonLabel="dropdown menu" code={`<div class="dropdown">
    <button type="button" class="btn btn-default btn-expand" id="dropdownMenuButton" data-bs-toggle="dropdown" aria-expanded="false">
      Dropdown button
    </button>
    <ul class="dropdown-menu">
      <li><button type="button" class="dropdown-item">Action</button></li>
      <li><hr class="dropdown-divider" /></li>
      <li><h6 class="dropdown-header">Dropdown header</h6></li>
      <li><a class="dropdown-item" href="#">Another action</a></li>
      <li><a class="dropdown-item disabled">A disabled action</a></li>
    </ul>
  </div>`} />
