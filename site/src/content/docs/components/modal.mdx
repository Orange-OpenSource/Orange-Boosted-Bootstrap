#### Sticky actions

Add `.modal-sticky-actions` to the `.modal` `<dialog>` to show the actions buttons as fixed on the modal bottom. The content will scroll independently of the action buttons, this ensures that primary actions remain continuously visible and accessible, especially when the modal contains a large amount of content. In this case the [full height variant](#full-height) is automatically applied.

#### Rounded corner

Rounded corner modals is a project-wide option therefore all your modals should either be rounded or not. Add `.use-rounded-corner-modal` on a top container (for example `<body>`) to use rounded corners.

<Callout type="warning">
  Rounded corners could be used in more emotional, immersive contexts or those tied to specific visual identities. **For standard or business-oriented usage, keep the default square corners.**
</Callout>

<Callout type="info">
  We use a `<div>` as a parent container because we cannot use `<body>` in an example.
</Callout>

<Example buttonLabel="dialog modal full" code={`<div class="use-rounded-corner-modal">

#### Close button

The close button may be hidden when the modal has a clear, visible alternative way to dismiss it, such as a single Cancel action or another explicit dismissal control. It may also be omitted when the modal represents a mandatory step in a controlled flow where dismissal is intentionally unavailable.

<Callout type="warning">
  The modal must always provide a discoverable and accessible way to close it.
</Callout>

#### Actions

There can be up to three actions buttons on the modal. These buttons typically include a primary action, a secondary action, and an optional tertiary action, allowing users to confirm, cancel, or perform additional tasks related to the modal's content. The buttons will automatically stack vertically on smaller screens but [that can be overridden using `.modal-footer-horizontal`](#horizontal-alignment).

<Example buttonLabel="dialog modal multiple actions" code={`<dialog id="demoModalMultipleActions" class="modal" aria-label="Demo modal" closedby="any">
    <div class="modal-header">
      <h3 class="modal-title">Modal title</h3>
      <button type="button" class="btn btn-close" commandfor="demoModalMultipleActions" command="close">
        <span class="visually-hidden">Close</span>
      </button>
    </div>
    <div class="modal-body">

As so seeing latter he should thirty whence. Steepest speaking up attended it as. Made neat an on be gave show snug tore.</p>
      <div class="modal-footer">

##### Horizontal alignment

By default the action buttons will stack vertically on smaller screens and align horizontally on larger screens. You can desactivate the vertical stacking using `.modal-footer-horizontal` on the `.modal-footer` container if needed. This is only advisable for smaller buttons labels.

<Example buttonLabel="dialog modal alignment" code={`<dialog id="demoModalAlignment" class="modal" aria-label="Demo modal" closedby="any">
    <div class="modal-header">
      <h3 class="modal-title">Modal title</h3>
    </div>
    <div class="modal-body">
      <p>Sportsman do offending supported extremity breakfast by listening. Decisively advantages nor expression unpleasing she led met.</p>

## Accessibility

- Provide an accessible name with `aria-labelledby` or `aria-label`.
- Keep a visible close control.
- Native dialog handles Escape and focus behavior by default.

## Notes

- Use `data-bs-role="modal"` on dialogs styled as OUDS modal.
- Use `data-bs-backdrop-static` on the dialog to prevent backdrop click dismissal.
