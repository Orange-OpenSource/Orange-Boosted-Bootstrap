## [[comp]] Interactive icon

An interactive icon is a UI element that triggers a user interaction, such as opening, closing, or toggling a state.

The interactive icon features defined states and can be used alone or within other components like static card or list items, or menus.

<Callout type="info" name="info-icons-svg-sprite" />

<Example buttonLabel="interactive icon" class="bd-example" code={`<button class="icon-interactive" aria-label="Default interactive icon">
    <svg aria-hidden="true">
      <use xlink:href="${getVersionedDocsPath('/assets/img/ouds-web-sprite.svg#heart-empty')}"/>
    </svg>
  </button>

  <button class="icon-interactive" aria-label="Default interactive icon">
    <span class="icon si si-settings" aria-hidden="true"></span>
  </button>`} />

### Sizes

Interactive icons are designed with maximum and minimum width and height, which constraints their size. They can however take any size within these boundaries.

They can be dimensioned using `.decorative-*-icon` classes on `svg` elements.

## [[comp]] Assistant icon

An assistant icon is a UI element that triggers an action or event featuring AI-powered capabilities, such as conversational assistance, content generation, or contextual suggestions.

The assistant icon combines standard interactive icon behaviors with AI-specific visual features to clearly indicate actions enhanced or powered by artificial intelligence.

You can use `.icon-assistant` class to indicate AI actions in a process or a flow. This class will add a specific icon and border color.

<Example buttonLabel="assistant icon" class="bd-example" code={`<button class="icon-assistant" aria-label="Default assistant icon"></button>`} />

<Callout type="warning" title="Transparency and older browsers">
An assistant icon does not have a transparent background on older browsers and Firefox because [`background-clip: border-area` is not fully supported](https://caniuse.com/wf-background-clip-border-area).

It's necessary to set `--bs-icon-bg` to its container background color to be compatible with most browsers. Make sure that the used variable isn't semi-transparent (ie. use background tokens instead of surface tokens).
</Callout>

If your browser is compatible, the following example will show two transparent assistant icons on a tertiary background. If not, only one non-transparent and one transparent icon.

<Example buttonLabel="assistant icon simulated transparent background" class="bd-example" code={`<div class="bg-tertiary">
    <button type="button" class="icon-assistant" aria-label="First transparent assistant icon"></button>

    <button type="button" class="icon-assistant" style="--bs-icon-bg: var(--bs-color-bg-tertiary);" aria-label="Second transparent assistant icon"></button>
  </div>`} />
