For both types of icon, OUDS Web has a common base `.icon` class that sets up default styles such as padding and content alignment. By default, `.icon` controls have no border nor background color, but still defines basic focus and hover styles. The `.icon` class is intended to be used in conjunction with our icon variants, or to serve as a basis for your own custom styles. The most basic icon is the `.icon` variant.

## [[comp]] Interactive icon

Interactive Icon is an icon component designed to trigger a user interaction (e.g., open, close, toggle a state). It includes defined interactive states and can be used independently or within other components such as buttons, inputs, or menus.

<Example buttonLabel="interactive icon" class="bd-example" code={`<button class="icon icon-interactive" aria-label="Default interactive icon">

      <use xlink:href="${getVersionedDocsPath('/assets/img/ouds-web-sprite.svg#heart-empty')}"/>
    </svg>

### Sizes

Interactive icons are meant to adapt to their container. They are not constrained to specific dimensions, and can be used at any size required by layout.

They can also be styled using `.decorative-*-icon` classes.

## [[comp]] Assistant icon

Assistant icon is an icon action component used to trigger an interaction with an AI-powered feature, such as conversational assistance, content generation, or contextual suggestions.

The assistant icon combines standard icon functions with AI-specific visual features to clearly indicate actions enhanced or powered by artificial intelligence.

You can use `.icon-assistant` class to indicate AI actions in a process or a flow. This class will add a specific icon and border color.

<Example buttonLabel="assistant icon" class="bd-example" code={`<button class="icon icon-assistant" aria-label="Default assistant icon"></button>
<button class="icon icon-assistant" aria-label="Default assistant icon"></button>`} />

<Callout type="warning" title="Transparency and older browsers">
An assistant icon does not have a transparent background on older browsers and Firefox because [`background-clip: border-area` is not fully supported](https://caniuse.com/wf-background-clip-border-area).

It's necessary to set `--bs-icon-bg` to its container background color to be compatible with most browsers. Make sure that the used variable isn't semi-transparent (ie. use background tokens instead of surface tokens).
</Callout>

If your browser is compatible, the following example will show two transparent assistant icons on a tertiary background. If not, only one non-transparent and one transparent icon.

<Example buttonLabel="assistant icon simulated transparent background" class="bd-btn-example" code={`<div class="bg-tertiary">
    <button type="button" class="icon icon-assistant" aria-label="First transparent assistant icon"></button>

    <button type="button" class="icon icon-assistant" style="--bs-icon-bg: var(--bs-color-bg-tertiary);" aria-label="Second transparent assistant icon"></button>
  </div>`} />
