Our accordions are based on our [items]([[docsref:/components/items]]). This is why they share the same structure, classes, and variants as items, with the addition of the interactive summary and expandable content specific to accordions.

### Approach

Accordions use native HTML `<details>` and `<summary>` elements. Activating the summary opens or closes the content without requiring the Collapse JavaScript plugin.

The basic structure includes:

* `.item` and `.item-accordion` on the `<details>` element.
* `.item-container` and `.item-interactive` on the `<summary>` element.
* `.item-content` as the container for the summary content.
* `.item-text-container` as the container for the summary text.
* `.item-slot` as a direct child of `<details>` for the expandable content.

### Accessibility

Use a clear, descriptive label in the `<summary>` so users can understand what content will be revealed. Native `<details>` and `<summary>` provide keyboard interaction and communicate the expanded or collapsed state without additional ARIA attributes.

## [[comp]] Accordion card item

An accordion card item is a UI element shaped like a self-contained card that reveals or hides related content within the current context.

The accordion card item is used when a more prominent visual grouping is needed compared to an accordion list item. The card can be displayed on its own or as part of a card-based accordion collection, and may feature a distinct background, outline, or rounded corners.

Add `.item-accordion` to the `.item` `<details>` element and `.item-interactive` to its `<summary>` element. The available options are described in the [common variants section](#common-variants).

        </span>
      </span>
    </summary>
    <div class="item-slot">
      test
    </div>
  </details>`} />

## [[comp]] Accordion list item

An accordion list item is a UI element shaped like a row, that reveals or hides related content within the current context.

Accordion items are typically stacked vertically, allowing users to scan sections and expand only the information they need.

Use `.item-list` as the surrounding container and `.item-accordion` on each expandable item. The available options are described in the [common variants section](#common-variants).

## Common variants

Accordions share item styles and can use the following options where appropriate for their content and context.

### With asset

The summary's `.item-content` can contain an optional leading container, a text container, and an optional trailing container, in that order. The expanding indicator is displayed separately from these containers.

#### Leading container

Use `.item-leading-container` to add content before the summary text, such as an icon or image.

### States

The summary reflects the accordion's current state and can be activated to reveal or hide its content.

#### Expanded

While content is loading, a skeleton can represent the accordion's layout. As with item skeletons, mark the loading container with `aria-busy="true"` and `inert` so its contents cannot be interacted with until they are ready.

### Sizes

Use `.item-small` on the `.item` or `.item-list` element for the small size. As with small items, avoid slots and asset size classes in the summary, and limit its text container to a label and/or description.

### Layout

Accordion layout follows the same alignment and width options as items.

#### Alignment

Summary content is vertically centered by default. Add `.item-top` to the `.item` or `.item-list` to align the content to the top.
