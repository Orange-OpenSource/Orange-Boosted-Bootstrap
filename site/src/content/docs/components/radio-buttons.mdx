## [[comp]] Radio button item

Radio button item is a UI element shaped like a row that allows users to select a single option from a set of mutually exclusive choices.

Unlike the [standalone radio button](#radio-button), the radio button item accommodates a broader range of contexts by enabling the toggling of visibility of additional text labels and icon assets.

They are implemented using `.radio-button-item` and `.control-item-*` classes, [see below](#control-item). Browser default radio buttons are replaced with the help of the selector `.control-item-indicator[type="radio"]`.

<Example buttonLabel="basic radio button items" code={`<fieldset class="control-items-list">

    <div class="radio-button-item">
      <div class="control-item-assets-container">
        <input class="control-item-indicator" type="radio" value="" id="radioButtonItemDefault" name="radioBasic" />
      </div>
      <div class="control-item-text-container">
        <label class="control-item-label" for="radioButtonItemDefault">Default radio button item</label>
      </div>
    </div>

    <div class="radio-button-item">
      <div class="control-item-assets-container">
        <input checked class="control-item-indicator" type="radio" value="" id="radioButtonItemDefault2" name="radioBasic" />
      </div>
      <div class="control-item-text-container">
        <label class="control-item-label" for="radioButtonItemDefault2">Checked radio button item</label>
      </div>
    </div>

  </fieldset>`} />

### Approach

#### Control item

<ControlItem />

#### Control items list

As radio button items are almost always grouped in a list, they should be enclosed in a `<fieldset> ` element with a `.control-items-list` class, this will handle automatic error text display when one of the control items input is invalid; you can add a `<legend>` element as a title for the list [read more](#fieldset-legend).

#### Read only

To create a read only radio button item, the input should be replaced by a `span` element with `role="radio"` and `aria-disabled="true"` attributes. All the radio button items in the group must be surrounded by a container with `role="radiogroup"` and `aria-readonly="true"` attributes. This is the only way to be compliant with ARIA specifications. The radio button item will be accessible to keyboard navigation and assistive technologies, thanks to `aria-labelledby` and `tabindex`, but other interactions will be prevented.

<Example buttonLabel="readonly radio button items" code={`<fieldset class="control-items-list">
    <div role="radiogroup" aria-readonly="true">

      <div class="radio-button-item">
        <div class="control-item-assets-container">
          <span class="control-item-indicator" role="radio" aria-disabled="true" tabindex="0" aria-checked="false" aria-labelledby="radioButtonItemReadonlyLabel" aria-describedby="radioButtonItemReadonlyExtraLabel radioButtonItemReadonlyDescription"></span>
        </div>
        <div class="control-item-text-container">
          <p class="control-item-label" id="radioButtonItemReadonlyLabel">Default readonly radio button item</p>
          <p class="radio-button-extra-label" id="radioButtonItemReadonlyExtraLabel">Extra label</p>
          <p class="control-item-description" id="radioButtonItemReadonlyDescription">Description text</p>
        </div>
      </div>

      <div class="radio-button-item">
        <div class="control-item-assets-container">
          <span class="control-item-indicator" role="radio" aria-disabled="true" tabindex="0" aria-checked="true" aria-labelledby="radioButtonItemReadonlyCheckedLabel"></span>
        </div>
        <div class="control-item-text-container">
          <p class="control-item-label" id="radioButtonItemReadonlyCheckedLabel">Checked readonly radio button item</p>
        </div>
      </div>

    </div>
  </fieldset>`} />

### Layout

#### Default

It's recommended to keep radio button item labels to no more than three words. When space is limited or when a long label, extra label or description text is required, the text can wrap, as this is preferable to truncation. The radio button indicator and the icon will remain vertically centered, until the `.control-item-assets-container` reaches a defined maximum height.

## [[comp]] Radio button

Radio button is a UI element that allows users to select a single option from a set of mutually exclusive choices.

Radio button, that lacks an additional icon asset or text label, provides greater flexibility when designing other components that incorporate a radio button.

<Callout type="warning" name="standalone-form-indicator" />

For the standalone radio button, we provide a completely different architecture than radio button item to ease the integration inside your projects.

<Example buttonLabel="radio button" code={`<label class="radio-button-standalone">
    <input class="control-item-indicator" type="radio" value="" />
    <span class="visually-hidden">Default radio button</span>
  </label>`} />

<BootstrapCompatibility>
<Callout type="warning">
  Be careful when using this, as you must implement the background on hover, focus and active states.
</Callout>

<Example buttonLabel="Bootstrap compatibility: standalone radio button" code={`<div>
    <input class="form-check-input" type="radio" value="" aria-label="Default standalone radio button (Bootstrap compatible)" />
  </div>`} />
</BootstrapCompatibility>

### States

#### Disabled

Add the `disabled` attribute to prevent interaction with the radio button and remove it from the keyboard tab order.

<Example buttonLabel="disabled standalone radio button" code={`<label class="radio-button-standalone">
    <input disabled class="control-item-indicator" type="radio" name="standaloneRadioDisabled" value="" />
    <span class="visually-hidden">Disabled radio button</span>
  </label>`} />

#### Read only

Radio inputs do not support the `readonly` attribute. Replace the inputs with elements that have `role="radio"` and `aria-disabled="true"`, and put them in a container with `role="radiogroup"` and `aria-readonly="true"`.

<Example buttonLabel="readonly standalone radio button" code={`<div class="radio-button-standalone" role="radiogroup" aria-readonly="true" aria-label="Read only radio button group">
    <span class="control-item-indicator" role="radio" aria-disabled="true" tabindex="0" aria-checked="true" aria-label="Selected option"></span>
  </div>`} />

#### Invalid

<Callout title="Prefer built-in form validation to handle client-side validation" type="info" name="form-field-validation" />

To manually mark a radio button as invalid, add `aria-invalid="true"` to the `.control-item-indicator` and use `aria-describedby` to associate an error message with it.

<Callout type="warning" name="control-standalone-invalid-no-icon" />

<Example buttonLabel="invalid standalone radio button" code={`<div>
    <label class="radio-button-standalone">
      <input class="control-item-indicator" type="radio" name="standaloneRadioInvalid" value="" aria-invalid="true" aria-describedby="radioButtonStandaloneError" />
      <span class="visually-hidden">Radio button</span>
    </label>
    <p id="radioButtonStandaloneError">Choose an available option.</p>
  </div>`} />
