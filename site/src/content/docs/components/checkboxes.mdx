## [[comp]] Checkbox item

Checkbox item is a UI element shaped like a row that allows users to select multiple options from a set of mutually non-exclusive choices.

Unlike the [standalone checkbox](#checkbox), the checkbox item accommodates a broader range of contexts by enabling the toggling of visibility of additional text labels and icon assets.

They are implemented using `.checkbox-item` and `.control-item-*` classes, [see below](#control-item). Browser default checkboxes are replaced with the help of the selector `.control-item-indicator[type="checkbox"]`.

<Example buttonLabel="basic checkbox items" code={`<fieldset class="control-items-list">

    <div class="checkbox-item">
      <div class="control-item-assets-container">
        <input class="control-item-indicator" type="checkbox" value="" id="checkboxItemDefault" />
      </div>
      <div class="control-item-text-container">
        <label class="control-item-label" for="checkboxItemDefault">Default checkbox item</label>
      </div>
    </div>

    <div class="checkbox-item">
      <div class="control-item-assets-container">
        <input checked class="control-item-indicator" type="checkbox" value="" id="checkboxItemDefault2" />
      </div>
      <div class="control-item-text-container">
        <label class="control-item-label" for="checkboxItemDefault2">Checked checkbox item</label>
      </div>
    </div>

  </fieldset>`} />

### Approach

#### Control item

<ControlItem />

#### Control items list

As checkbox items are almost always grouped in a list, they should be enclosed in a `<fieldset> ` element with a `.control-items-list` class, this will handle automatic error text display when one of the control items input is invalid; you can add a `<legend>` element as a title for the list [read more](#fieldset-legend). It is also possible to use a `<ul>` list in place of the `<fieldset>` (and `<li>`s for the items) but the error text display will be up to you [see an example](#with-ul). If the checkbox item is not part of a group and you need the automatic error text display, you can enclose it inside a `.checkbox-item-container` [read more](#unique).

#### Read only

To create a read only checkbox item, the input should be replaced by a `span` element with `role="checkbox"`, `aria-readonly="true"` and `aria-disabled="true"` attributes. The checkbox item will be accessible to keyboard navigation and assistive technologies, thanks to `aria-labelledby` and `tabindex`, but other interactions will be prevented.

<Example buttonLabel="readonly checkbox items" class="bd-example-indeterminate" addStackblitzJs code={`<fieldset class="control-items-list">

    <div class="checkbox-item">
      <div class="control-item-assets-container">
        <span class="control-item-indicator" role="checkbox" aria-readonly="true" aria-disabled="true" tabindex="0" aria-checked="false" aria-labelledby="checkboxItemReadonlyLabel"></span>
      </div>
      <div class="control-item-text-container">
        <p class="control-item-label" id="checkboxItemReadonlyLabel">Default readonly checkbox item</p>
      </div>
    </div>

    <div class="checkbox-item">
      <div class="control-item-assets-container">

      </div>
      <div class="control-item-text-container">
        <p class="control-item-label" id="checkboxItemReadonlyCheckedLabel">Checked readonly checkbox item</p>
      </div>

It's recommended to keep checkbox item labels to no more than three words. ## [[comp]] Checkbox

Checkbox is a UI element that enables users to select multiple options from a set of mutually non-exclusive choices.

Checkbox, that lacks an additional icon asset or text label, offers greater flexibility when designing other components that incorporate a checkbox.

<Callout type="warning" name="standalone-form-indicator" />

For the standalone checkbox, we provide a completely different architecture than checkbox item to ease the integration inside your projects.

<Example buttonLabel="checkbox" code={`<label class="checkbox-standalone">
    <input class="control-item-indicator" type="checkbox" value="" />
    <span class="visually-hidden">Checkbox</span>
  </label>`} />

<BootstrapCompatibility>
<Callout type="warning">
  Be careful when using this, as you must implement the background on hover, focus and active states.
</Callout>

<Example buttonLabel="Bootstrap compatibility: standalone checkbox" code={`<div style="position: relative">
    <input class="form-check-input" type="checkbox" id="checkboxNoLabel" value="" aria-label="Standalone checkbox (Bootstrap compatible)" />
  </div>`} />
</BootstrapCompatibility>

### States

#### Disabled

Add the `disabled` attribute to prevent interaction with the checkbox and remove it from the keyboard tab order.

<Example buttonLabel="disabled standalone checkbox" code={`<label class="checkbox-standalone">
    <input disabled class="control-item-indicator" type="checkbox" value="" />
    <span class="visually-hidden">Disabled checkbox</span>
  </label>`} />

#### Read only

Checkbox inputs do not support the `readonly` attribute. Replace the input with an element that has `role="checkbox"`, `aria-readonly="true"`, `aria-disabled="true"`, `aria-checked`, and `tabindex="0"`.

<Example buttonLabel="readonly standalone checkbox" code={`<span class="checkbox-standalone">
    <span class="control-item-indicator" role="checkbox" aria-readonly="true" aria-disabled="true" tabindex="0" aria-checked="true" aria-label="Read only checkbox"></span>
  </span>`} />

#### Invalid

<Callout title="Prefer built-in form validation to handle client-side validation" type="info" name="form-field-validation" />

To manually mark a checkbox as invalid, add `aria-invalid="true"` to the `.control-item-indicator` and use `aria-describedby` to associate an error message with it.

<Callout type="warning" name="control-standalone-invalid-no-icon" />

<Example buttonLabel="invalid standalone checkbox" code={`<div>
    <label class="checkbox-standalone">
      <input class="control-item-indicator" type="checkbox" value="" aria-invalid="true" aria-describedby="checkboxStandaloneError" />
      <span class="visually-hidden">Checkbox</span>
    </label>
    <p id="checkboxStandaloneError">Select this option to continue.</p>
  </div>`} />
