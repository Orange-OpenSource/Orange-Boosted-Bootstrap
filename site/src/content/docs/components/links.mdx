## [[comp]] Link

Link is a UI element that allows to navigate from one location to another, either within the same page or across different pages in the same resource, or to an external resource.

The link’s main function is navigation, and it visually and semantically conveys its interactive nature.

Use OUDS Web `.link` class to set up styles such as padding and content alignment to display standalone links. Standalone links should not be used inline within a sentence or a paragraph. In that case, use only a `<a>` tag as described in the [reboot page]([[docsref:/foundation/reboot#links]]).

By default, `.link` defines focus, hover and active styles similar to the `<a>` tag.

<Example showToolbar={false} code={`<a class="link" href="#">This is an example of link</a>`} />

`:visited` standalone links don’t have any specific styling.

### Alternative tag

The `.link` classes are designed to be used with the `<a>` element. However, you can also use these classes on `<button>` elements.

<Example buttonLabel="link with a button tag" code={`<button class="link" type="submit">Button link</button>`} />

### Variants

#### On colored background

OUDS Web offers a few variations to use on [colored backgrounds]([[docsref:/utilities/background#colored-background]]). Their accessibility (readability) is ensured by suitable semi-opaque backgrounds.

<Callout type="warning" title="Heads up!">
  Background utilities used to make colored backgrounds, should always be used with the appropriate color theme (see an example below). Please refer to [colored backgrounds documentation]([[docsref:/utilities/background#colored-backgrounds]]).
</Callout>

<Example buttonLabel="links on colored backgrounds" class="p-none bd-first-rounded" code={`<div class="bg-surface-brand-primary p-large">
    <div data-bs-theme="${getMode('modes-on-brand-primary')}">
      <a class="link link-on-colored-bg" href="#">This is an example of link</a>
    </div>
  </div>
  <div class="bg-surface-status-negative-emphasized p-large">
    <div data-bs-theme="${getMode('modes-on-status-negative-emphasized')}">
      <a class="link link-on-colored-bg" href="#">This is an example of link</a>
    </div>
  </div>`} />

#### With chevron

Add `.link-chevron` to enhance your link with a chevron on the right side. Use the additional `.link-previous` class to display the chevron on the left side.

<Example buttonLabel="links with chevron" code={`<div><a class="link link-chevron" href="#">Link with chevron</a></div>
  <div><a class="link link-chevron link-previous" href="#">Link with a previous chevron</a></div>
  <div style="width:20rem;">
    <div><a class="link link-chevron" href="#">This is an example of a link on multiple lines with chevron</a></div>
    <div><a class="link link-chevron link-previous" href="#">This is an example of a link on multiple lines with a previous chevron</a></div>
  </div>`} />

#### With external icon

Add `.link-external` to enhance your link with an external icon on the right side.

<Callout type="info">
  For accessibility reasons, it is recommended to add a visually hidden text to indicate that the link opens an external resource. Take a look at [some more complete accessibility guidelines](https://a11y-guidelines.orange.com/en/web/develop/common-navigation/#warn-the-user-when-opening-a-new-window).
</Callout>

<Example buttonLabel="links with external icon" class="d-flex flex-column gap-medium" code={`<a class="link link-external" href="#">Link with external icon<span class="visually-hidden">&nbsp;(external link)</span></a>`} />

#### With icon

<Callout type="info" name="info-icons-svg-sprite" />

The `.icon-link` class modifies the default link styles to enhance their appearance and quickly align any pairing of icon and text. Alignment is set via inline flexbox styling and a default `gap` value. We style the underline with a custom offset and color. Icons are automatically sized to `1em` to best match their associated text’s `font-size`.

If really needed, you can use a font icon associated to the `.icon` class to set correct parameters for the `font-size` and `line-height`.

<Callout type="info">
  When icons are purely decorative, they should be hidden from assistive technologies using `aria-hidden="true"`, as we’ve done in our links examples. See [icons accessibility]([[docsref:/components/icon#icons-accessibility]]) for more info.
</Callout>

Take a regular `<a>` element, add `.icon-link`, and insert an icon on the left of your link text. The icon is automatically sized, placed, and colored.

<Example buttonLabel="links with icon" code={`<div>
    <a class="link icon-link" href="#">
      <svg aria-hidden="true">
        <use xlink:href="${getVersionedDocsPath('/assets/img/ouds-web-sprite.svg#heart-empty"/>')}
      </svg>
      This is an example of a link with an SVG icon
    </a>
  </div>
  <div>
    <a class="link icon-link" href="#">
      <span class="icon si si-settings" aria-hidden="true"></span>
      This is an example of a link with an icon font
    </a>
  </div>`} />

<Example buttonLabel="Bootstrap compatibility: links with chevron"  code={`<a class="icon-link" href="#">

### States

#### Disabled

Make links look inactive by adding the `aria-disabled="true"` attribute to any `<a>` element. Disabled links have `pointer-events: none` applied to, preventing hover and active states from triggering.

Disabled links using `<a>` *should not* include the `href` attribute. In case you need to keep the `href`, please refer to [disabled link accessibility warning](#disabled-link-accessibility-warning).

<Example buttonLabel="disabled links" code={`<div><a class="link" aria-disabled="true">This is an example of a disabled link</a></div>
  <div><a class="link link-chevron" aria-disabled="true">This is an example of a disabled link with chevron</a></div>
  <div>
    <a class="link icon-link" aria-disabled="true">
      <svg aria-hidden="true">
        <use xlink:href="${getVersionedDocsPath('/assets/img/ouds-web-sprite.svg#heart-empty"/>')}
      </svg>
      This is an example of a link with an icon
    </a>
  </div>`} />

##### Disabled link accessibility warning

To cover cases where you have to keep the `href` attribute on a disabled link, the style on `[aria-disabled="true"]` uses `pointer-events: none` to try to disable the link functionality of `<a>`s. Note that this CSS property is not yet standardized for HTML, but all modern browsers support it. In addition, even in browsers that do support `pointer-events: none`, keyboard navigation remains unaffected, meaning that sighted keyboard users and users of assistive technologies will still be able to activate these links.

If the disabled link does not convey any useful information, you can include a `tabindex="-1"` attribute in addition to `aria-disabled="true"` on these links to prevent them from receiving keyboard focus, and use custom JavaScript to disable their functionality altogether.
However, if the disabled link conveys useful information for users, it must remain focusable and you should not add the `tabindex="-1"` attribute to keep it accessible to keyboard navigation.

<Example buttonLabel="disabled links keeping `href` attribute" code={`<div><a href="#" class="link" tabindex="-1" aria-disabled="true">Disabled link without any useful information</a></div>
  <div><a href="#" class="link" aria-disabled="true">Keyboard focusable disabled link</a></div>`} />

### Sizes

Links are available in two sizes and two densities. Add `.link-small` for small font-size link. Add `.link-compact` for smaller padding around the link. You can combine both classes to have a small and compact link.

<Callout type="warning">
  Compact and small sizes are not recommended for accessibility reasons because of the interactive area being reduced.

  For the 2.5.5 WCAG criterion on target size enhanced and while using a list of compact links, make sure to space them enough to avoid accidental interactions. If you follow the [2.5.5 WCAG criterion](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html), the minimum height and width of the link with the spaces around should equal `44px x 44px`.
</Callout>

<Example buttonLabel="links sizes" class="d-flex flex-column align-items-start gap-xsmall" code={`<a class="link" href="#">This is an example of a link</a>
  <a class="link link-small" href="#">This is an example of a small link</a>
  <a class="link link-compact" href="#">This is an example of a compact link</a>
  <a class="link link-compact link-small" href="#">This is an example of a small compact link</a>`} />

## [[comp]] Expand link

An expand link is a UI element that reveals or hides additional content through a text link.

The expand link feature is displayed through a dropdown with selectable values. It is ideal for inline contexts where minimal visual weight is needed, maintaining a clean layout while still providing access to additional information.

Use OUDS Web `.link` class to set up styles such as padding and content alignment to display standalone links. By default, `.link` defines focus, hover and active styles similar to the `<a>` tag.

<Callout type="info">
  The expand link uses a `<button>` element to trigger the dropdown.
</Callout>

<Example showToolbar={false} code={`<div class="dropdown">
    <button type="button" class="link link-expand" data-bs-toggle="dropdown" aria-expanded="false">Expand</button>
    <ul class="dropdown-menu">
      <li><a class="dropdown-item" href="#">Action</a></li>
      <li><a class="dropdown-item" href="#">Another action</a></li>
      <li><a class="dropdown-item" href="#">Something else here</a></li>
    </ul>
  </div>`} />
